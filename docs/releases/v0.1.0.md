First public build.

- Reference in, low-poly model out: a Claude agent builds the model in Blender stage by stage — spec, form, look, review, delivery.
- Two routes to the shape: the agent by script (included in your Claude plan) or a generator on fal.ai (Tripo P2, Trellis 2, Hunyuan 3.1), paid per run with the price on the button.
- Claude by subscription (the `claude` CLI login) or by Anthropic API key.
- Starts Blender with its own server script — no add-on to install.
- Viewer for GLB / FBX / OBJ: colors, clay, clay + wireframe, all matte.

macOS, Apple Silicon. The app is not signed: right-click → Open → Open on first launch.
