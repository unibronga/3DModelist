First public release. Reference in, low-poly model out: a Claude agent builds the model in Blender stage by stage — spec, form, look, review, delivery — and you watch and steer it in one window.

**New in this build**

- **Live model and versions.** After every scene-script run the studio exports a quick snapshot from Blender: the model is visible in 3D while it is being built, every step stays as a version (v1, v2…), versions open from the same camera angle, and the agent can restore any of them.
- **Marks on the model.** Press Mark (M), click a part — it lights up under the cursor — and type what to fix. The agent gets the part's name, the point in Blender coordinates and a snapshot with numbered marks.
- **Check tools**: the reference floating over the view, model parts, views that match the agent's sheet, a floor grid in meters, a 1.8 m person for scale, light controls and a Normals view with flipped faces in red.
- **Numbers against the spec**: size and triangle count turn green or orange depending on the spec.
- Softer slate dark theme with blue-violet buttons; the window no longer flashes light on start.

**Also inside**

- Two routes to the shape: the agent by script (included in your Claude plan) or an image-to-3D generator on fal.ai, paid per run with the price on the button.
- Claude by subscription (the `claude` CLI login) or by Anthropic API key; the modeler and the critic are your choice.
- Blender starts headless with its own server script — no add-on to install.
- Seven interface languages, light / dark / system theme, interface size.

macOS, Apple Silicon. The app is not signed: right-click the app → Open → Open on first launch.
