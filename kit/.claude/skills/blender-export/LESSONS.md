# Разборы: чем оплачены правила экспорта

## Персонаж (25–26 сентября)

- **Blender 5.2: видео** включается через
  `scene.render.image_settings.media_type = "VIDEO"`, затем `ffmpeg.format =
  "MPEG4"`, `codec = "H264"`; значения `FFMPEG` в `file_format` больше нет
  (ошибка «enum FFMPEG not found»). Настройки рендера в живой сцене владельца
  снимать снимком и восстанавливать в `finally`.
- **OBJ из GUI-Blender** (cwd = «/») пишет `map_Kd ../../../../../../file.png`
  даже с `path_mode="RELATIVE"`. Текстуру сохранить рядом
  (`img.filepath_raw = ...; img.save()`), в `.mtl` руками поставить
  `map_Kd <файл>`, `Ks 0`, `illum 1`, и проверить повторным импортом.
- **GLB проверять по JSON-чанку и повторным импортом** в
  `Blender -b --factory-startup`: число трис, картинки (`image/jpeg`), узлы и
  родители, анимации с каналами по узлам. Параметрам экспорта не верить.
- **FBX от Tripo с квадами** импортируется штатно (`import_scene.fbx`);
  генератор смотрит на -X — доворот `-90°` по Z, проверять числами по
  положению носков ботинок относительно голеней.


## Ряды пропсов (26 сентября 2026)

- `prop_export()`: GLB по предмету — временно ставить объект в нуль координат
  (в ряду он стоит со сдвигом по X, иначе в GLB уедет трансляция), плюс весь ряд
  одним `*_all.glb`. Без Draco, `export_apply=True`, без анимаций и скинов.
- Проверка — повторный импорт всех файлов ряда одним фоновым Blender, а не
  чтение параметров экспорта.
