# Подача: материал, свет, камера, рендер

Форма решает 60% впечатления, подача — остальные 40%.
Разборы провалов — в `LESSONS.md` рядом.

## Всё по спеке — стиля заранее нет

Палитра, матовость/блеск, металл, подача — из спеки этапа 0 (скил
`blender-reference`), снятой с референса. Своих «профильных» чисел нет.

**Материал — плоский цвет** (выход пайплайна — low-poly без карт):
`pbr(name, srgb('#RRGGBB'), metallic=…, roughness=…)` — значения из спеки.
Карт нет, запекания нет, UV не нужны. Разные части — разные материалы,
детализация живёт в форме.

**Свет превью — чтобы читалась форма**, а не «стиль»: ключ + заливка +
контровой. Если референс — сцена со своим светом, превью ставится под него.

## Свет

`three_point(target, distance, height, key, fill, rim)` — схема по умолчанию.

- **Key** лепит форму. Сбоку и сверху, не в лоб.
- **Fill** раскрывает тени, в 3-5 раз слабее ключа. Уравняешь — форма сплющится.
- **Rim** обводит силуэт. **Без него объект влипает в фон** — самая частая
  причина «рендер выглядит дёшево».

**Мягкий свет = большой источник.** У `AREA` крутить `size`: размер источника
важнее мощности. `world_color(color, strength)` вместо HDRI — дёшево и
предсказуемо. `studio_floor()` — подложка, ловящая тень.

## Камера

`orbit_camera(angle_deg, elevation_deg, distance)`, `frame_objects(margin=1.2)`.

⛔ **Всегда задавать `distance=` и `target=` руками.** Без них `orbit_camera` и
`turntable` считают дистанцию по всей сцене вместе с полом — камера улетает,
объект превращается в точку.

**Ракурс 3/4 сверху** (`angle≈40°, elevation≈20-25°`) читается лучше всего.
Строго фронтальный делает вещь плоской.

## Движки

**EEVEE** — секунды на кадр, по умолчанию всю дорогу.
**Cycles** — только финал: `setup_render("CYCLES", samples=128, res=(1920,1440))`.
На Mac Metal-GPU включается сам, первый кадр медленнее из-за компиляции шейдеров.

`view_transform="AgX"` по умолчанию не пережигает светлые места.

🔴 **Прозрачный фон включается в ДВУХ местах.** `setup_render(transparent=True)`
ставит `film_transparent`, но `render()` сам выставляет `color_mode` — без
аргумента в самом вызове альфа теряется:

```python
render("out.png", transparent=True)      # именно здесь, не только в setup_render
```

Глазом не ловится (картинка выглядит нормально) — ловится тем, что маска силуэта
покрывает весь кадр.

## Если рендер плохой — читать по списку

1. **Плоско, нет объёма** — нет rim либо fill равен key.
2. **Всё серое и мутное** — roughness одинаковый на всём.
3. **Чёрные провалы** — нет `world_color`, нечему подсвечивать тени.
4. **Пересвет** — источник слишком близко (энергия падает квадратично).
5. **Объект висит в пустоте** — нет пола и контактной тени.
6. **Зернит** — мало samples или выключено `use_denoising`.

## Непонятный артефакт — сначала снять сцену целиком

🔴 **Не крутить параметры вслепую.** Широкий план с большого расстояния отвечает
за один кадр на вопрос, на который перебор настроек не отвечает вовсе:

```python
camera("Wide", location=(14, -18, 9), target=(0, 0, 1), lens=28)
render("renders/_diag_wide.png")
```

Второй дешёвый приём — исключать по одному: скрыть пол, гасить источники по
очереди, отрендерить сцену без объекта.

⚠️ Диагностические прогоны идут по живой сцене и меняют её. Выводы сверять на
свежей пересборке, иначе они противоречат друг другу.

## Быстрая петля

Полный прогон со светом и высоким разрешением — для сдачи, не для подбора.
Пока подбираются пропорции и цвет: `samples=32`, `res=(900, 700)`, один ракурс,
20-40 секунд.

## PBR — только если владелец явно назвал фотореализм

`metallic` булев по смыслу: 0 или 1. `roughness` — главный рычаг: полированный
металл 0.05-0.15, глянцевый пластик 0.15-0.3, резина 0.7-0.9, ткань 0.8-1.0.
Цвет металла лежит в base_color (золото `(1.0, 0.77, 0.34)`, медь
`(0.95, 0.64, 0.54)`). Base color не бывает чисто чёрным и чисто белым —
реальные диэлектрики в 0.03-0.85. `coat=0.3…0.5` даёт второй острый блик.

## Cel-shading — когда нужен рисованный вид

Diffuse BSDF → `Shader to RGB` → ColorRamp с интерполяцией `CONSTANT` (3-4
ступени) → Emission. Только EEVEE. Нормаль обязательно подать в Diffuse, иначе
рельеф пропадёт.

Контур по силуэту: Solidify наружу с `use_flip_normals=True` и
`material_offset=1`, второй слот — тёмный Emission.
🔴 У материала контура обязателен `use_backface_culling=True`, иначе вывернутая
оболочка закроет модель тёмным силуэтом.
