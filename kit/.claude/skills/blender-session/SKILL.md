# Связь с Blender

Не этап, а предусловие: одна команда перед первой командой моделирования.

```bash
tools/bl --ping
```

Успех — версия Blender, текущий .blend, сводка по сцене.

## Откуда в Blender сокет

```
tools/bl ──► tools/blender_bridge.py ──► TCP localhost:9876 ──► сервер внутри Blender ──► bpy
```

Сервер внутри Blender — один из двух, протокол у них общий:

1. **Свой сервер 3DModelist** — `blender/modelist_server.py`. Его поднимает
   кнопка «Запустить Blender» в настройках 3DModelist: Blender стартует с
   `--python blender/modelist_server.py`. Ничего ставить в Blender не нужно.
2. **Официальный аддон Blender Lab MCP** (`lab_blender_org.mcp`), если он у
   человека уже стоит: `Edit ▸ Preferences ▸ Add-ons ▸ MCP` — галка
   `Auto Start` или кнопка `Start`.

Порт по умолчанию 9876; другой задаётся `BLENDER_MCP_PORT` (студия передаёт
его сама).

## Связи нет — проверять в этом порядке

1. **Blender не запущен** — `pgrep -fl -i blender`. Сказать человеку: в
   3DModelist «Настройки ▸ Blender ▸ Запустить Blender».
2. **Blender открыт, но без сервера** (запустили обычным значком, аддона нет) —
   тот же совет: закрыть и запустить из студии.
3. **Порт занят чем-то другим** — `lsof -nP -iTCP:9876 -sTCP:LISTEN`.

## Два режима

**С окном — по умолчанию.** Человек видит модель вживую, крутит вьюпорт.

**Без окна — для пакетной работы.**

```bash
"<путь к Blender>" --background --python blender/modelist_server.py
```

⚠️ Сначала проверить, не открыт ли Blender с сервером: второй экземпляр не
займёт порт, а команды уйдут в первый. Признак — «команда прошла, а на экране
ничего».

## Смена .blend

Мост исполняет код в том файле, который открыт **сейчас**. Перед новой моделью —
`reset_scene()` либо явная загрузка. Проверять через `--ping`.

🔴 `reset_scene()` необратимо чистит открытый файл. Если в Blender открыт
именованный .blend с работой человека — сначала спросить, а не чистить.

## Безопасность

Сервер исполняет присланный python без песочницы. Поэтому дисциплина на
агенте: **скрипты сцен работают только внутри рабочей папки**, наружу не
пишут, чужие файлы не читают, сеть не дёргают.
